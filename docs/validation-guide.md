# 新界面本地验证包

本包来自当前源码，包含未发布的五页原生界面。基础版本号见 VERSION.txt，
不是 GitHub 上同版本的正式发布包。源码基准提交、未提交状态及文件指纹见
VERSION.txt 和 SOURCE-MANIFEST.json。

1. 完整解压到一个新的可写目录，例如 `D:\Apps\xray-pilot-ui-validation`。
2. 双击 xray-manager.exe，按首次设置向导准备依赖、添加配置、检查并确认启动。
   默认数据目录为解压后的 xray-pilot\data，首次验证建议不接管系统代理。
3. 在向导或“设置 → Core 与依赖”下载 / 修复官方依赖并保存设置。
   本包不包含 Xray Core；自动部署从 XTLS/Xray-core 官方发布页获取并校验。
   离线准备、配置示例及详细操作见 README.md。
4. 若更新已有安装，先通过“退出程序（停止 Core 并恢复代理）”完全退出旧后台，
   备份数据，再同时替换三个 exe。不要将新界面连接到仍运行的旧版后台。

建议检查：首次设置、配置切换和持久草稿、检查预览 / 明确应用、运行版本诊断、
日志筛选、浅色 / 深色 / 跟随系统、关闭到托盘、仅退出界面及完整退出。
关闭窗口会收起到托盘；“仅退出界面”会保留后台和 Core。
已有端口被其他 Core 占用时，请调整配置端口。

本次导入修复建议检查：带 api.tag 的原生配置不再误报 Unknown outboundTag；
缺项但可解析的 JSON 对象可以“保存待补充配置”，在概览查看字段提示后继续编辑；
长 JSON 在最小窗口中可滚动，标题及保存 / 取消按钮保持可见。
配置页、导入和预览的 JSON 区域随父容器尺寸调整；放大、缩小及还原窗口时，
检查编辑空间是否相应变化，底部校验按钮是否与内容保持分离。
配置包含较多资源覆盖提示时，预览显示中文摘要；展开“资源与自动恢复限制”，
滚动到最后一项，检查提示文字不重叠，返回 / 确认按钮保持可见。
同时检查断线 / 恢复 / 错误提示展开后的配置页、设置和诊断详情、长日志，
以及长名称确认弹窗。底部“完整消息”可滚动查看和复制状态消息全文。
保存不会启动 Core；“检查并预览”仍执行官方 Core 校验。
文件导入默认保留设置中的资源目录，按需勾选使用配置文件所在目录。

自动回归与隔离 Windows Core / 托盘冒烟记录见 docs/ui-implementation.md，
各页布局的复核结果见 docs/ui-layout-review.md。已知遗留见 docs/phase0-2-backlog.md。
真实系统代理、实际登录启动及完整人工交互仍需验证。
校验下载文件可使用 PowerShell 的 Get-FileHash，与包外 SHA256SUMS 比较。
