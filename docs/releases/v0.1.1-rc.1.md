# Xray Pilot v0.1.1-rc.1

用于 Windows x64 验证的预发布版，范围为 Phase 0–2。Core 由用户自行提供，可直接选择 `C:\v2rayN\bin\Xray\xray.exe`。

## 本次交付

- 提供配置导入、原生 JSON 编辑、校验和差异预览、明确应用、历史预览与回滚。
- 支持独立后台、Global / Direct、Windows 托盘和当前用户登录自启设置。
- 包含 C01–C15 的事务、去重、租约、资源、IPC 和重连修复。
- 关闭 C16：已有 Profile 时重开 GUI 能正确加载保存的 Core 路径和自启选项；迟到响应不能覆盖用户编辑或后续保存。
- README 改为安装、配置和部署指南，解压包附示例、验证脚本和 VERSION.txt。

## 下载与开始验证

在 [发布页](https://github.com/muidea/xray-pilot/releases/tag/v0.1.1-rc.1) 下载 `xray-pilot-0.1.1-rc.1-windows-x64.zip` 及 `SHA256SUMS`，核对 SHA-256 后完整解压。详细步骤见 [README](../../README.md)。从旧版本升级前先完全退出并备份整个数据目录。

建议使用新的验证数据目录，避免影响现有配置：

```powershell
.\xray-manager.exe --data-dir "D:\Xray Pilot Verify"
```

1. 在 Settings 选择现有官方 Core 和资源目录，保存。
2. 导入随包的 examples/local-direct.json，若端口与现有代理工具冲突则修改端口。
3. 选择 Direct，校验、检查差异并应用，确认 Core Running。
4. 使用 README 中的 curl 命令显式连接 HTTP 入站，核对真实请求。
5. 只退出 GUI 后重开，确认 Core 保持运行，Core 路径和已保存选项正确显示；核对设置后再次保存，确认没有回退为默认值。
6. 停止 Core 并查询状态。Global、真实 WinINet 恢复及实际登录启动请按自己的环境单独验证。

反馈问题时附上 VERSION.txt、触发步骤、状态和脱敏日志；操作结果不确定时同时保留 request ID。
