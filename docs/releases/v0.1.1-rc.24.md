# Xray Pilot v0.1.1-rc.24

Windows x64 本地验证版，在 `v0.1.1-rc.23` 的基础上深度结合 Xray Core 的 `geosite.dat` / `geoip.dat` 数据能力与路由规则，重构精简 PAC 模型、编译器与交互流程。**本版尚未发布到 GitHub Release**。

## 本次变化

- **原生 `geosite.dat` / `geoip.dat` 解析与路由预测增强（`xray-config`）**：
  - 新增零外部依赖、边界检查的纯 Rust Protobuf 读取器 `xray_config::geodata`（`GeoSiteIndex`、`GeoIpIndex`、`GeoData`），支持 `@attr` / `@!attr` 属性筛选及 `ext:*.dat:tag` 外部数据文件；
  - 静态路由模拟（`simulate_with_geo` / Supervisor `TestRunningRoute`）可直接匹配 `geosite:` / `geoip:` / `ext:` 规则。
- **GeoSite 感知 PAC 编译与冗余子域折叠（`xray-model` / `xray-pac` / `xray-supervisor`）**：
  - 精简统一 `PacMode`（`AutoRules`、`DirectList`、`ProxyList`、`All`、`Custom`）与 `PacDraft { mode, geosites, domains, script, port }`，移除多余的旧版模板/生成布尔标志；
  - 默认 `AutoRules` 模式直接编译当前配置 `/routing/rules` 中的 `geosite:` / `domain:` / `full:` / `keyword:` 条目，采用 ES3 顶层对象哈希表与母域折叠（如 `tieba.baidu.com` / `full:www.baidu.com` 折叠入 `baidu.com`），大幅缩减脚本体积（超过 512 KiB 主动提醒）；
  - 严格保持故障关闭安全约束：前序 Proxy / Blackhole 规则若包含无法用 PAC 表达的条件（含 `geosite:` 中的正则条目、`geoip:` 等），自动抑制后续 `DIRECT` 分支并将兜底交给 Xray Core；
  - `Supervisor` 在校验与发布阶段同时感知冻结资源目录与 `asset_root` 下的 `geosite.dat`。
- **精简 PAC 页面与路由 GeoSite 快捷能力（`xray-manager-app`）**：
  - 移除旧版多余的“生成并检查模板”手动中间步骤，改为策略或列表变更后自动编译与语法校验，页面精简为「分流模式与 GeoSite」「自定义域名清单（仅清单模式显示）」「测试与一键应用」及折叠「高级设置」；
  - `DirectList` / `ProxyList` 模式内置常用 GeoSite 速选芯片（`private` / `cn` / `geolocation-!cn` / `category-ads-all` / `apple-cn` / `google` / `github`）与可搜索全量分组浏览器；“从路由规则提取”同步提取 `geosite:` 分组与普通域名；
  - 配置路由编辑器新增一键 **“国内外分流预设 (GeoSite)”** 按钮与常用 `+ geosite:` 快捷标签。

## 验证

全工作区 **233 项**通过，7 项需显式环境用例忽略（其中 `xray-config` 23 passed、`xray-pac` 19 passed、`pac_flow` 13 passed、`xray-manager-app` 101 passed / 1 ignored）；`cargo fmt --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy、`git diff --check` 全部通过。
