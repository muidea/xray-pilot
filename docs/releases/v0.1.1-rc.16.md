# Xray Pilot v0.1.1-rc.16

Windows x64 本地验证版，简化配置历史管理并补充诊断页功能说明。**本版尚未发布到 GitHub Release**。

## 配置历史

- 历史列表不再每行直接“载入为草稿”，改为单一 **比较并载入…** 操作。
- 打开差异对话框后再决定：`-` 为当前草稿、`+` 为历史版本；取消不修改当前草稿。
- 确认后才替换草稿，仍需重新检查、预览和应用；历史行标记当前运行版本。

## 诊断页

- **WinHTTP 会话代理**：明确用途为查看独立于 WinINet 的 WinHTTP 默认会话代理来源；只读，不修改机器级/WinHTTP 设置。
- **路由静态预测**：明确用于核对目标会命中哪条 routing 规则和出站，不发起连接、不代替实际访问。
- 路由高级条件（入站 Tag、已知 IP、来源、用户/协议、属性）收进“高级匹配条件（可选）”，主表单只保留目标与端口/网络。
- 按钮改为 **预测命中规则与出站**。

## 验证

全工作区 **206 项**常规回归通过，7 项需显式环境用例忽略；新增历史差异确认/载入测试和 PAC 步骤测试。Linux/Windows GNU 严格 Clippy、fmt 通过。

真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍需按包内验证说明执行。
