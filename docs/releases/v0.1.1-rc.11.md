# Xray Pilot v0.1.1-rc.11

Windows x64 本地验证版，合并托盘退出入口，调整首次向导弹窗按钮排版，并修复无配置时 PAC 页显示 JSON 解析错误的问题。**本版尚未发布到 GitHub Release**。

## 本次变化

- **托盘退出合并**：托盘中原来的“仅退出界面”和“退出程序”合并为一个 **退出…** 项。点击后打开确认对话框，可选择：
  - 仅退出界面，后台和 Core 继续运行；
  - 退出整个程序，停止 Core 并恢复代理。
  可勾选“记住为默认退出方式”，下次打开对话框时预选；默认值为“仅退出界面”。
- **首次向导按钮**：**保存并继续** 与 **稍后设置，进入总览** 改为同一水平行显示。
- **PAC 空配置**：没有选择配置或编辑器为空时，不再显示 `当前 JSON 无法解析：EOF while parsing...`；改为“尚未选择配置”提示，模板按钮禁用。
- 延续 rc.9：启动恢复、PAC 域名清单、诊断核对和统一对话框。

## 验证范围

全工作区 **200 项**常规回归通过，7 项需显式环境用例忽略；Linux 与 Windows GNU 严格 Clippy、fmt 通过。真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍需按包内验证说明执行。
