# Xray Pilot v0.1.1-rc.13

Windows x64 本地验证版，进一步修复 PAC “仅代理清单”空清单仍走代理的问题，并确保从 PAC 页直接应用当前草稿。**本版尚未发布到 GitHub Release**。

## 本次变化

- **PAC DIRECT 目标**：Windows 目标同时设置 `AUTO_PROXY_URL` 和 `PROXY_TYPE_DIRECT`，使 PAC 返回的 `DIRECT` 被 WinINet 采用；这是 rc.12 起的关键修复。
- **确保应用当前草稿**：PAC 页新增 **检查并预览 PAC 应用** 按钮，直接保存当前范围/清单并以 PAC 模式检查预览，避免只修改草稿但当前运行版本仍是旧脚本。
- **模式选择更可靠**：点击代理范围会重新启用内置模板；若当前是自定义脚本，页面显示明确提示。空清单的“仅代理清单”脚本明确返回 `DIRECT`。
- **回归**：新增空清单脚本、Supervisor 实际发布、Windows 快照 `DIRECT` 位测试。全工作区 **203 项**常规回归通过，7 项需显式环境用例忽略。

## 重要验证提示

修改 PAC 范围或清单后，当前运行版本不会自动变化。请在 PAC 页点击 **检查并预览 PAC 应用**，或回到配置页重新检查并应用。若仍看到普通域名走代理，请记录 PAC URL 内容，以及当前用户 `ProxyEnable`、`AutoConfigURL`、`ProxyServer` 值用于定位。

## 验证范围

真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍需按包内验证说明执行。
