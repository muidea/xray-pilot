# Xray Pilot v0.1.1-rc.12

Windows x64 本地验证版，修复“仅代理清单中的域名”在清单为空时仍代理全部访问的问题。**本版尚未发布到 GitHub Release**。

## 本次变化

- **PAC DIRECT 生效**：Windows PAC 目标恢复 `PROXY_TYPE_DIRECT` 位（与 `AUTO_PROXY_URL` 同时设置）。此前只设置 PAC URL，WinINet 可能不采用脚本返回的 `DIRECT`，导致“仅代理清单”为空时普通域名仍走代理。现在空清单脚本返回 `DIRECT`，WinINet 应遵循该结果。
- **回归**：新增空代理清单脚本测试和 Supervisor 实际发布测试，确认普通域名返回 `DIRECT`、清单域名返回 `PROXY`。
- **风险说明**：PAC 服务不可达时 WinINet 可能回退直连；这是 PAC 模式的固有风险，需在 V10 中实测。
- 延续 rc.11：单一托盘退出确认、首次向导按钮同行、无配置 PAC 不显示 JSON 解析错误。

## 验证范围

全工作区 **202 项**常规回归通过，7 项需显式环境用例忽略；Linux 与 Windows GNU 严格 Clippy、fmt 通过。真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍需按包内验证说明执行。
