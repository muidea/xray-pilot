# Xray Pilot v0.1.1-rc.7

Windows x64 本地验证版，修复配置更新后 PAC 页未刷新本地入口的问题。**本版尚未发布到 GitHub Release**。

## 本次变化

- **PAC 入口刷新**：更新配置新增、改名或调整 HTTP/Mixed 入站后，PAC 页会从当前编辑器重新枚举入口；当前标签失效时自动选择第一个可用入口，不再一直提示“请先添加回环、无认证入口”。
- **具体错误提示**：没有 HTTP/Mixed 入站、入口不是回环、带认证或端口无效时，PAC 页显示实际原因，而不是统一提示。
- **回归**：新增“配置从无入口更新为新 HTTP 入口”的 PAC 端点刷新测试；全工作区 **189 项**常规回归通过，7 项需显式环境用例忽略。
- 延续 rc.6 的界面与 PAC 简化：主题在设置页、顶栏无程序/主题按钮、底部无“完整消息”按钮、PAC 默认内置模板、复杂能力收在高级设置。

## 下载与升级

本包为 Linux 交叉构建 Windows GNU 目标的本地验证包，文件名 `xray-pilot-0.1.1-rc.7-windows-x64.zip`，校验和见同目录 `SHA256SUMS`。验证基线提交与源码指纹见 `VERSION.txt` 和 `SOURCE-MANIFEST.json`；可能记录 `source_dirty=true`，不能当作已发布版本。

完全退出旧后台和 Core，备份 data 后同时替换三个 EXE。不要让新界面连接仍在运行的旧后台。

## 验证范围

真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍需按 [验证说明](../validation-guide.md) 与 [遗留清单](../phase0-2-backlog.md) 执行。PAC 执行测试使用有界 JavaScript 引擎；`dnsResolve` / `isInNet` 等网络辅助函数报告 Unsupported。F01 容量策略、F02/F03/F05 高级组合和 V01/V02/V04–V10 的系统验收边界继续保留。
