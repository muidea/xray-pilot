# Xray Pilot v0.1.1-rc.9

Windows x64 本地验证版，新增启动时恢复上次 Core 运行状态、PAC 域名清单、诊断数据核对和统一对话框。**本版尚未发布到 GitHub Release**。

## 本次变化

- **启动恢复**：设置新增 **启动时恢复上次 Core 运行状态**（默认开启）。上次退出前 Core 正在运行，则界面连接后台后自动启动上次已应用版本；手动停止不会恢复。只恢复 Core，不自动重新接管系统代理。另保留“后台启动后总是自动连接”选项。
- **PAC 域名清单**：内置模板新增 **全部代理 / 仅代理清单 / 清单直连** 三种范围，可直接添加、移除域名（支持 `example.com`、`*.example.com`、`full:example.com`），不再需要手写脚本或使用统一策略编辑器。端口、导入、从配置生成和脚本编辑仍在高级设置。
- **诊断核对**：移除“真实网络连通性 / 实际出口”未检测占位；新增代理模式、恢复状态和最近错误；WinHTTP 显示真实会话访问类型、代理和绕过；TCP 延迟显示目标地址与握手毫秒数；操作证据限制高度并可滚动。
- **对话框统一**：确认、创建/导入、重命名、未保存退出和应用预览统一标题字号、说明层级、滚动区域、分隔线与按钮行；危险操作使用错误色按钮。
- **验证包文档**：只附带 `docs/验证说明.md` 和 `docs/发布说明.md`，不再打包设计、评审、交接、历史收口和 UI 原型。

## 验证范围

全工作区 **197 项**常规回归通过，7 项需显式环境用例忽略；Linux 与 Windows GNU 严格 Clippy、fmt 通过。真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍需按包内验证说明执行。PAC 执行测试使用有界 JavaScript 引擎；`dnsResolve` / `isInNet` 等网络辅助函数报告 Unsupported。F01 容量策略、F02/F03/F05 高级组合和 V01/V02/V04–V10 的系统验收边界继续保留。
