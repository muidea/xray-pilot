# Xray Pilot v0.1.1-rc.2

Windows x64 预发布验证版，新增首次部署的官方依赖下载管理，以及浅色/深色/跟随系统的显示选择。

## 本次变化

- GUI Settings 新增 Download / repair official Core，从 [Xray 官方](https://github.com/XTLS/Xray-core/releases) 下载指定版本包，默认 v26.11.9，验证官方 SHA-256 并安装 Core、geoip.dat、geosite.dat。
- 支持受管版本列表、完整性检查、健康副本复用、新目录修复和已安装版本选择，旧安装及运行代次保留。
- 随包提供 windows-dependencies.ps1，支持无界面依赖准备、指定版本及官方离线包安装；无需 Python 或 Rust。
- Settings → Appearance 提供 Follow system、Light、Dark，立即生效并记住选择。
- README 使用官方获取和部署流程，移除开发机路径作为正式安装示例。

## 已完成验证

Linux 74 项、Windows 原生 52 项回归及两平台严格 Clippy 通过。官方依赖实际下载、复用、损坏修复、失败保护和离线输入验收通过。最终 Windows release 已使用受管官方 Core 完成 GUI/Core/IPC/Job 与停滞客户端监督冒烟；真实系统代理和登录任务未改动。浅色/深色实际 Windows 窗口已核对，三种偏好切换与持久化有正式回归。

## 验证建议

从 [发布页](https://github.com/muidea/xray-pilot/releases/tag/v0.1.1-rc.2) 下载 Windows x64 zip 和 SHA256SUMS，核对后完整解压。首次使用新的数据目录，按 [README](../../README.md) 下载官方依赖、保存设置、导入示例并以 Direct 模式校验和应用。

检查重开后 Core/资源设置和主题是否保留。下载完成之前修改设置时，原选择应保留；再次下载健康版本应复用已有安装。需要修复时先通过 Check installed dependencies 核对，修复后旧目录仍保留。

开发及验证记录见 [依赖和偏好说明](../installation-and-dependencies.md)。Windows 真实代理往返、实际登录、跨用户访问和系统故障矩阵等未完成验收继续保留。PAC、TUN、Windows 服务、应用自动更新和历史自动清理尚未提供。
