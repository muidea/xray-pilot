# Xray Pilot v0.1.1-rc.21

Windows x64 本地验证版，在上一版的基础上新增日志复制与文件导出功能，支持单条日志、筛选结果及持久化会话日志（含轮转备份）一键复制和导出。**本版尚未发布到 GitHub Release**。

## 本次变化

- **日志复制与导出增强**：
  - **日志** 页每条日志右侧新增独立 **复制** 按钮；**复制筛选结果** 在空结果时禁用，复制后提供明确的条数提示；
  - Windows 下 **日志** 页工具栏新增 **导出日志…**，支持将当前筛选日志保存为 `.log` / `.txt` UTF-8 文本文件（默认 `xray-pilot-logs.txt`）；
  - **日志** 页底部与 **设置 → 数据与存储 → 会话日志** 均新增 **复制会话日志 / 复制日志内容** 与（Windows 下）**导出会话日志…**（默认 `xray-pilot-supervisor.log`），按时间顺序自动拼接轮转备份 `logs/supervisor.log.1` 与 `logs/supervisor.log`；存储页同时补充 **复制日志路径**。
- **包含 v0.1.1-rc.19 / rc.20 全部改进**：
  - `--background` 开机自启时通过 DWM `DWMWA_CLOAK` 防闪烁并仅驻留系统托盘，支持左键双击托盘图标及各类托盘动作统一唤醒聚焦；
  - PAC 批量域名粘贴/编辑/导入导出、从路由规则提取（跳过 `geosite:` / `regexp:` / `ext:` 并提示边界）、搜索筛选、虚拟滚动大列表及 ES3 对象查表式内置模板。

## 验证

全工作区 **219 项**常规回归通过，7 项需显式环境用例忽略（新增日志单条复制、筛选复制、`.log.1` + `.log` 拼接复制、导出写入与错误路径及存储页复制 UI 单测）；`cargo fmt --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy、`git diff --check` 全部通过。

Windows 原生 `rfd::FileDialog` 导出对话框、真实桌面下的 `DWMWA_CLOAK` 开机隐藏、托盘左键双击及 WinINet / PAC URL 往返仍需按 V01 / V02 / V08 / V10 实机验收。
