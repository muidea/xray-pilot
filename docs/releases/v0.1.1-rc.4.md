# Xray Pilot v0.1.1-rc.4

Windows x64 预发布验证版，交付五页中文界面与统一程序图标，并修复草稿保存、设置读取及后台应用后的草稿恢复问题。

## 本次变化

- 总览、配置、诊断、日志、设置五页界面，支持浅色、深色及跟随系统；清理重复状态说明，统一托盘、任务栏、标题栏和 EXE 图标。
- 配置导入保留原生 JSON，支持保存待补充内容并提示缺少字段；修正 API 内部出站误报。JSON 编辑、导入及预览随容器自适应，改善长内容滚动和控件对齐。
- 草稿保存失败时拦截正常退出，保留修改，提供重试 / 导出 / 明确放弃；设置重读不覆盖用户编辑，后台应用后草稿基准同步持久化，重开不再误报冲突。
- 成功运行操作后清除旧请求错误，保留历史失败和本地写入错误；Core 校验失败的原始诊断可在会话日志中查看。
- 大 IPC 响应只编码一次，并移至受限后台任务，改善慢客户端并存时的响应性。
- 验证包采用正式版本名称，包内记录源码提交与文件指纹，不使用时间戳或临时用途后缀。

## 下载与升级

从 [发布页](https://github.com/muidea/xray-pilot/releases/tag/v0.1.1-rc.4) 下载 `xray-pilot-0.1.1-rc.4-windows-x64.zip` 与 `SHA256SUMS`，核对后完整解压到可写目录。

完全退出旧后台和 Core，备份 data 后同时更新三个 EXE。不要让新界面连接仍在运行的旧后台。默认 data 位于程序安装目录；自定义目录继续使用相同的 `--data-dir` 参数。

本包不附带 Xray Core；首次设置或“设置 → Core 与依赖”可从 XTLS/Xray-core 官方发布下载并校验。详细步骤见 [README](../../README.md) 和 [验证指南](../validation-guide.md)。

## 验证范围

本轮代码阶段 Linux 工作区 123 项、Windows 原生 GUI 57 项 / Supervisor 18 项 / 官方 Core 专项 1 项通过，两平台严格 Clippy 通过；Windows 原生窗口图标及隔离生命周期已核对。证据及测试边界见 [C18–C20 收口](../phase0-2-c18-20-closeout.md)。最终交付包在发布前另执行 Windows release 冒烟。

真实 WinINet、实际登录 / 权限拒绝、跨用户安全、完整桌面交互和系统故障矩阵尚未全部验收；依赖覆盖、启动就绪、结构化编辑仍有边界，资源与历史自动清理尚未实现。详见 [遗留清单](../phase0-2-backlog.md)。PAC、TUN、Windows 服务和应用自动更新不在本版范围内。
