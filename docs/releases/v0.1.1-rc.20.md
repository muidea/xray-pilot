# Xray Pilot v0.1.1-rc.20

Windows x64 本地验证版，在上一版 PAC 批量管理与模板优化的基础上，修复 `--background` 开机自启动时主界面仍弹出显示的问题，支持仅驻留系统托盘并完善托盘双击唤醒。**本版尚未发布到 GitHub Release**。

## 本次变化

- **开机自启动仅驻留系统托盘（`--background`）**：
  - 修复 `eframe` 在首帧渲染后强制 `set_visible(true)` 覆盖 `with_visible(false)` 的问题；
  - Windows 下以 `--background` 启动且托盘可用时，先通过 DWM `DWMWA_CLOAK` 遮蔽窗口避免首帧闪烁，待第 2 帧完成隐藏后再解除遮蔽，使程序仅显示系统托盘图标；托盘创建失败时自动回退显示主窗口；
  - 托盘唤醒链路（左键双击图标、菜单 **打开 Xray Pilot**、选择配置、**退出…**、未提交配置时 **启动** 等）统一清理待隐藏状态并解除遮蔽、聚焦显示主窗口；
  - 新增托盘左键双击事件处理，同步将设置页开机自启文案更新为 **登录 Windows 后自启（隐藏到系统托盘）**。
- **包含 v0.1.1-rc.19 全部 PAC 改进**：
  - 逗号/分号/空格分隔多域名添加、批量粘贴/编辑对话框、导入/导出纯文本列表、从路由规则提取（跳过 `geosite:` / `regexp:` / `ext:` 并提示作用边界）、关键词搜索与类型筛选、多选批量移除与固定高度虚拟滚动列表，以及顶层 ES3 对象字面量查表式内置 PAC 模板。

## 验证

全工作区 **218 项**常规回归通过，7 项需显式环境用例忽略（新增 `xray-manager` `--background` 首帧后隐藏/解除遮蔽状态机及托盘打开取消隐藏 2 项单元测试）；`cargo fmt --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy、`git diff --check` 全部通过。

真实 Windows 桌面下的 `DWMWA_CLOAK` 防闪烁效果、托盘左键双击、计划任务 `--background` 开机自启以及 WinINet / PAC URL 往返仍需按 V01 / V02 / V08 / V10 实机验收。
