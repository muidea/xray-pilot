# Xray Pilot v0.1.1-rc.14

Windows x64 本地验证版，修复 PAC 添加域名时未切回模板、导致域名清单保存但实际不生效的问题。**本版尚未发布到 GitHub Release**。

## 根因与修复

- 当 PAC 草稿此前是“从当前配置生成”或“自定义脚本”时（`template=false`、`generated=true`），添加域名只保存了 `domains`，没有把草稿切回内置模板。应用时 Supervisor 仍使用旧的生成/自定义脚本，因此 PAC 内容仍是“全部代理”。
- 现在添加域名会强制：
  - `template=true`；
  - `generated=false`；
  - 若范围为“全部代理”，切换为“仅代理清单”；
  - 立即保存 PAC 草稿（不等页面结束）。
- 更改代理范围、移除域名也会立即保存。
- 新增回归：自定义/生成草稿添加域名后必须切回模板；Workspace `gui.json` 的 PAC 草稿模式/域名/脚本可完整往返。

## 验证包

全工作区 **204 项**常规回归通过，7 项需显式环境用例忽略；Linux 与 Windows GNU 严格 Clippy、fmt 通过。验证包仍只包含验证说明、发布说明、两个必要脚本、示例和三个 EXE。

## 复测

PAC 页选择“仅代理清单中的域名”，添加一个域名后立即检查并应用；PAC 内容应包含域名条件和 `return "DIRECT"` 兜底，不应再是单一“全部代理”脚本。修改后当前运行版本仍需点击“检查并预览 PAC 应用”或回到配置页重新应用。
