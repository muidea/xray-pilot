# Xray Pilot v0.1.1-rc.26

Windows x64 本地验证版，在 `v0.1.1-rc.25` 的基础上新增 GUI 单实例保护与唤醒交接，防止设置开机自启后出现两个 `Xray Pilot` 系统托盘图标。**本版尚未发布到 GitHub Release**。

## 本次变化

- **GUI 单实例保护与窗口激活交接（`xray-manager-app`）**：
  - 新增 `single_instance` 模块：在 Windows 下为同一当前用户 SID 与数据目录绑定专属命名管道锁（`\\.\pipe\xray-pilot-gui-<hash>`，`first_pipe_instance(true)` 与当前用户 DACL、`reject_remote_clients(true)`）；
  - 当开机自启任务（`--background`）已在托盘后台运行时，无论是用户手动再次双击启动 `xray-manager.exe`、Windows 登录后自动恢复先前打开的窗口，还是重复触发后台自启：
    - 二次前台启动不再创建第二个窗口或第二个托盘图标，而是向已运行实例发送 `OPEN` 激活信号，直接解除 DWM 遮蔽、显示并聚焦已有主窗口后平滑退出；
    - 二次 `--background` 启动发送静默 `PING` 保活检查后即退出，不会意外弹出主界面，确保系统托盘区始终只存在一个图标；
  - 保留 `windows-smoke.ps1 -Gui` 等通过独立临时 `--data-dir` 启动的隔离验证场景互不干扰。
- **回归测试**：
  - `single_instance::tests::open_signal_requests_activation_and_ping_stays_quiet`
  - `single_instance::tests::malformed_signal_returns_error_without_activating`
  - `app_tests::single_instance_activation_cancels_background_hide_and_reveals_window`
