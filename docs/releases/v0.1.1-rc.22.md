# Xray Pilot v0.1.1-rc.22

Windows x64 本地验证版，在上一版的基础上定位并修复了开机自启等场景触发 `PROXY_LEASE_CONFLICT` 后的诊断盲区与恢复期锁定问题，提供用户确认的冲突解除操作并允许在纯代理冲突恢复期间调整及保存启动设置。**本版尚未发布到 GitHub Release**。

## 本次变化

- **外部系统代理冲突（`PROXY_LEASE_CONFLICT`）可观测性与错误保留**：
  - WinINet 租约冲突提示与 `logs/supervisor.log` 现在包含 `current`、`expected` 与 `root` 的完整代理快照对比（`flags`、`server`、`bypass`、`pac`），便于确认外部变更来源；
  - `Supervisor::recover` 与 `stop_generation` 将代理释放冲突记录写入持久化会话日志；
  - `Supervisor::handle` 在处于恢复阻塞状态时保留原始恢复错误码，不被常规拦截返回的 `RECOVERY_REQUIRED` 覆盖。
- **显式确认的安全解除入口（不覆盖外部系统代理）**：
  - 新增 `Command::ResolveProxyConflict` 与 `xrayctl resolve-proxy-conflict`，在严格校验 `installation.json`、配置/启动任务证据及历史事务均干净后，保留当前 Windows 系统代理设置并将 `root` / `expected` 同步为当前快照、解除租约冲突；
  - 界面 **总览** 恢复提示卡片与 **诊断 → 本机状态** 新增 **保留当前系统代理并解除冲突…** 按钮及二次确认弹窗；若存在 `PROXY_RECOVERY_REQUIRED` 等证据损坏情况则保持禁用并拒绝解除。
- **纯代理冲突恢复期支持修改并保存设置**：
  - 当阻塞仅来自代理租约冲突且安装标识、启动计划任务与配置保存证据本身健康时，允许执行 `Command::SaveSettings`，**设置 → 启动行为** 中的 **登录 Windows 后自启（隐藏到系统托盘）** 及 **保存设置** 保持可用，不再因 `PROXY_LEASE_CONFLICT` 导致无法取消开机自启动；若存在 `STARTUP_CONFLICT`、`SETTINGS_CONFLICT` 或操作/回滚恢复阻塞则继续锁定。

## 验证

全工作区 **224 项**常规回归通过，7 项需显式环境用例忽略（包含 `windows-integration`、`xray-supervisor` 与 `xray-manager-app` 新增的代理冲突解除、非代理恢复保护及恢复期 `SaveSettings` 取消开机自启回归）；`cargo fmt --check`、Linux 与 `x86_64-pc-windows-gnu` 双目标严格 Clippy、`git diff --check` 全部通过。

真实 Windows 下的 WinINet / PAC 冲突复现、**保留当前系统代理并解除冲突…**、冲突状态下取消/保存开机自启及原有 V01 / V02 / V08 / V10 流程仍需实机验收。
