# Xray Pilot v0.1.1-rc.10

Windows x64 本地验证版，功能与 rc.9 相同，仅精简验证包 `scripts` 目录。**本版尚未发布到 GitHub Release**。

## 本次变化

- **验证包脚本精简**：只保留
  - `scripts/windows-dependencies.ps1`：官方依赖安装/状态/选择，供命令行离线或修复依赖使用；
  - `scripts/windows-proxy-snapshot.ps1`：验证前后只读记录/比较 WinINet 五项设置。
- 移除开发期自测/审计脚本：`windows-smoke.ps1`、`windows-portable-check.ps1`、`windows-ipc-audit.ps1`、`windows-dependencies-check.ps1`。这些脚本仍保留在源码仓库，用于开发回归，不属于功能验证包。
- 延续 rc.9：启动恢复上次 Core 运行状态、PAC 域名清单模板、诊断数据核对和统一对话框。

## 验证范围

全工作区 **197 项**常规回归通过，7 项需显式环境用例忽略；Linux 与 Windows GNU 严格 Clippy、fmt 通过。验证包仅保留 `docs/验证说明.md`、`docs/发布说明.md`、README、示例、两个必要脚本和三个 EXE。

真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍需按包内验证说明执行。
