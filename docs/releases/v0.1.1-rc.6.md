# Xray Pilot v0.1.1-rc.6

Windows x64 本地验证版，按使用反馈调整界面并简化 PAC：**主题设置回到设置页**、顶栏移除程序菜单与主题快捷按钮、底部移除“完整消息”按钮；PAC 默认使用内置模板，复杂能力收在高级设置。**本版尚未发布到 GitHub Release**。

## 本次变化

- **界面**：顶栏只保留页面标题；主题在 **设置 → 外观** 选择；退出等程序操作继续只通过托盘/窗口关闭入口完成。底部状态栏保留简短消息，移除“完整消息”按钮。
- **PAC 默认模板**：PAC 页默认展示内置模板——`localhost`、纯主机名、`.lan` / `.local` 直连，其余请求通过当前 HTTP/Mixed 入口进入 Xray；应用时按当前入口重新生成，端口变化不会沿用旧值。
- **简化 PAC 管理**：端口、从当前配置生成、导入 PAC 文件和脚本编辑移入“高级设置”；移除统一域名策略编辑器；保留检查、执行测试和当前 PAC URL。
- **延续能力**：不可变 PAC 发布、租约、端口/版本切换、失败补偿、启动恢复、持久化日志、WinHTTP 只读诊断、Dynamic 依赖、Mixed 入站、路由冲突提示和 TCP 延迟探测。
- **Windows 目标**：PAC 仅设置 `AUTO_PROXY_URL`，不设隐式 DIRECT；Supervisor 被强制结束后 WinINet 的回退行为仍需 V10 实测。

## 下载与升级

本包为 Linux 交叉构建 Windows GNU 目标的本地验证包，文件名 `xray-pilot-0.1.1-rc.6-windows-x64.zip`，校验和见同目录 `SHA256SUMS`。验证基线提交与源码指纹见 `VERSION.txt` 和 `SOURCE-MANIFEST.json`；可能记录 `source_dirty=true`，不能当作已发布版本。

完全退出旧后台和 Core，备份 data 后同时替换三个 EXE。不要让新界面连接仍在运行的旧后台。默认 data 位于程序安装目录；自定义目录继续使用相同 `--data-dir`。

本包不附带 Xray Core；首次设置或“设置 → Core 与依赖”从 XTLS/Xray-core 官方发布页下载并校验。

## 验证范围

当前源码 Linux 工作区 **188 项**常规回归通过，7 项需显式环境用例忽略；Linux 与 Windows GNU 全目标严格 Clippy、格式检查通过。真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍需按 [验证说明](../validation-guide.md) 与 [遗留清单](../phase0-2-backlog.md) 执行。

PAC 执行测试使用内置有界 JavaScript 引擎，`dnsResolve` / `isInNet` 等网络辅助函数报告 Unsupported；不是完整内存隔离。F01 历史容量/自动维护、F02/F03/F05 高级组合和 V01/V02/V04–V10 的系统验收边界继续保留。
