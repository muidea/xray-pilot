# Xray Pilot v0.1.1-rc.18

Windows x64 本地验证版，修正未分类依赖配置的启动恢复提示和自动恢复策略。**本版尚未发布到 GitHub Release**。

## 本次变化

- **未分类字段**：`resources.complete=false` 但无动态外部文件时，不再显示“自动恢复不可用”的启动提示；自动连接成功即静默运行，异常退出后的自动恢复也允许尝试，由 Core 实际启动结果兜底。
- **动态外部文件**：仍视为内容不受冻结控制，跳过自动连接和自动恢复，保留非致命提示。
- 两种情况下都不再返回致命 `RESOURCE_REVALIDATION_REQUIRED`，也不把 Supervisor 标记为 blocked。
- 资源预览只对动态外部文件注明自动恢复不可用；未分类字段说明为“启动时由 Core 接受/拒绝”。
- 设置和验证说明同步更新。

## 验证

全工作区 **208 项**常规回归通过，7 项需显式环境用例忽略；依赖不完整配置的自动启动回归已更新。Linux/Windows GNU 严格 Clippy、fmt 通过。

真实注销/登录、动态文件变更、断电和完整 Windows 启动场景仍需按 V01/V02/V04–V10 验收。
