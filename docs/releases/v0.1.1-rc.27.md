# Xray Pilot v0.1.1-rc.27

Windows x64 本地验证版，在 `v0.1.1-rc.26`（单实例防重复托盘图标）的基础上，统一调整所有日志时间戳按运行环境本地时区格式化显示。**本版尚未发布到 GitHub Release**。

## 本次变化

- **本地时区日志时间戳格式化（`xray-runtime` / `xray-supervisor` / `xray-manager-app`）**：
  - [xray-runtime](file:///home/rangh/aispace/xray-pilot/crates/xray-runtime/src/lib.rs) 新增 `local_timestamp()` 与 `localize_log_line()`：日志时间统一以运行主机本地时区格式化为 `[YYYY-MM-DD HH:MM:SS.mmm ±HH:MM]`（例如 `[2026-11-14 20:54:38.123 +08:00]`），同时在进程入口通过 `init_local_offset()` 预采集本地偏移（Windows 下同时动态支持 `now_local()` 与夏令时切换）；
  - 写入内存环形缓冲与落盘 `logs/supervisor.log` / `supervisor.log.1` 的 Supervisor/Core 日志直接以本地时区记录，避免先前 UTC `Z` 时间与 Xray Core 本体输出相差数小时的问题；
  - 界面 **日志** 页中的 `[操作 / 信息]` / `[操作 / 错误]` 等界面操作记录同步携带本地时区时间戳；读取/展示历史日志或导出会话日志时，若包含旧版 `[...Z]` UTC 前缀，也会自动转换为当前本地时区格式显示。
- **回归测试**：
  - `xray_runtime::log_tests::timestamps_and_legacy_utc_prefixes_format_with_timezone_offset`
  - `xray_manager::app::ui::tests::log_rows_show_local_timestamps_for_operations_and_localize_utc_prefixes`
