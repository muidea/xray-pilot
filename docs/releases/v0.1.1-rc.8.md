# Xray Pilot v0.1.1-rc.8

Windows x64 本地验证版，内容等同于 rc.7 的 PAC 入口刷新修复，但**清理验证包文档**。**本版尚未发布到 GitHub Release**。

## 本次变化

- **验证包文档精简**：不再打包设计文档、代码评审、交接文档、历史收口记录、UI 原型和内部状态文档；包内只保留 `docs/验证说明.md`、`docs/发布说明.md`、`README.md`、`LICENSE`、示例和 Windows 脚本。
- **PAC 修复延续**：配置更新新增、改名或调整 HTTP/Mixed 入站后，PAC 页会重新枚举入口；旧标签失效时自动选择第一个可用入口，并在全部不可用时显示具体原因。
- **界面延续**：主题在设置页、顶栏无程序/主题按钮、底部无“完整消息”按钮；PAC 默认内置模板，复杂能力收在高级设置。
- 全工作区 **189 项**常规回归通过，7 项需显式环境用例忽略；Linux 与 Windows GNU 严格 Clippy、fmt 通过。

## 下载与升级

本包为 Linux 交叉构建 Windows GNU 目标的本地验证包，文件名 `xray-pilot-0.1.1-rc.8-windows-x64.zip`，校验和见同目录 `SHA256SUMS`。验证基线提交与源码指纹见 `VERSION.txt` 和 `SOURCE-MANIFEST.json`；可能记录 `source_dirty=true`，不能当作已发布版本。

完全退出旧后台和 Core，备份 data 后同时替换三个 EXE。不要让新界面连接仍在运行的旧后台。

按包内 `docs/验证说明.md` 执行 PAC、界面、日志、诊断和系统代理验证。真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍未执行；F01 容量策略、F02/F03/F05 高级组合和 V01/V02/V04–V10 的系统验收边界继续保留。
