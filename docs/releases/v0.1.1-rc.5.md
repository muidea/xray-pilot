# Xray Pilot v0.1.1-rc.5

Windows x64 本地验证版，新增 PAC 自动代理与内置模板、持久化日志、WinHTTP 只读诊断、Dynamic 依赖、Mixed 入站、路由冲突提示和 TCP 延迟探测。**本版为上一轮本地验证包，尚未发布到 GitHub Release**，仅用于当前源码功能验证。

## 本次变化

- **PAC 自动代理**：内置默认模板（本地/局域网直连，其余进入 Xray），高级设置支持从原生域名规则生成、导入/编辑、语法检查和有界 `FindProxyForURL` 测试；不可变回环 HTTP 发布；Windows `AUTO_PROXY_URL`（不隐式 DIRECT） 目标；租约、端口/版本切换、失败补偿和启动恢复。
- **诊断与运维**：WinHTTP 只读诊断；本地入口/PAC 状态分层；持久化日志（UTC 时间戳、代次上下文、凭据脱敏、4 MiB 轮转、7 天备份）；出站 TCP 延迟探测。
- **入站与依赖**：Xray `mixed` 入站就绪与 HTTP/Mixed 系统代理端点；扩展常见传输、DNS、sockopt 等原生依赖覆盖；绝对外部文件可显式 Dynamic opt-in 并重校验。
- **维护**：`xrayctl maintenance` 将 PAC 发布纳入引用分析和超期孤儿回收。
- **GUI**：新增 PAC 页；配置页支持 PAC 模式；托盘状态和 PAC 切换；草稿级撤销/重做；导出敏感信息确认。

## 下载与升级

本包为本地验证包，文件名 `xray-pilot-0.1.1-rc.5-windows-x64.zip`，校验和见同目录 `SHA256SUMS`。验证基线提交与源码指纹见 `VERSION.txt` 和 `SOURCE-MANIFEST.json`；源码可能包含未提交修改（`source_dirty=true`），不能把该包当作已发布版本。

完全退出旧后台和 Core，备份 data 后同时替换三个 EXE。不要让新界面连接仍在运行的旧后台。默认 data 位于程序安装目录；自定义目录继续使用相同 `--data-dir`。

本包不附带 Xray Core；首次设置或“设置 → Core 与依赖”从 XTLS/Xray-core 官方发布页下载并校验。

## 验证范围

当前源码 Linux 工作区 **188 项**常规回归通过，7 项需显式环境用例忽略；Linux 与 Windows GNU 全目标严格 Clippy、格式检查通过。真实 WinINet / PAC URL 往返、Windows 原生桌面、官方 Core 和远端 CI 仍需按 [验证说明](../validation-guide.md) 与 [遗留清单](../phase0-2-backlog.md) 执行。
