# Xray Pilot v0.1.1-rc.15

Windows x64 本地验证版，重构 PAC 页为 1–5 步流程，明确“生成并检查”“测试”“应用”的作用。**本版尚未发布到 GitHub Release**。

## PAC 页调整

- **步骤 1 · 选择代理范围**：全部代理 / 仅代理清单 / 清单直连；切换立即保存草稿。
- **步骤 2 · 添加代理域名**：添加/移除后立即保存，并强制切回内置模板；清单为空时明确提示。
- **步骤 3 · 生成并检查模板**：合并原“重新生成模板”和“检查脚本”；显示模板来源、检查状态和兼容性提示。
- **步骤 4 · 执行 FindProxyForURL 测试**：输入测试 URL，点击 **测试当前模板**，显示 DIRECT/PROXY 结果和原始数据。
- **步骤 5 · 应用到运行版本**：显示当前 PAC URL；若运行脚本与草稿哈希不一致，明确提示“当前运行版本仍是旧脚本”；点击 **检查并预览 PAC 应用** 进入应用预览。
- 高级设置保留端口、导入、从当前配置生成和自定义脚本编辑。
