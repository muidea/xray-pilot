# Xray Pilot v0.1.1-rc.3

Windows x64 预发布修复版，解决隐藏窗口后托盘菜单无法退出的问题，并将默认数据目录调整到安装目录下。

## 本次变化

- 托盘 Open、Exit GUI (keep Core)、Exit and restore proxy 可以唤醒隐藏窗口，--background 启动后也能退出。
- 完整退出等待当前写操作完成，收到后台关闭成功响应后再关闭 GUI；失败显示错误和 request ID。
- Windows 默认数据目录为程序目录下的 data，GUI、Supervisor、CLI 与依赖安装脚本一致，且不随工作目录变化。保留 --data-dir / -DataDir。
- README 更新安装和升级说明。旧版 LOCALAPPDATA 数据不会自动迁移或合并；继续使用旧数据请显式指定原目录。
- 保留 rc.2 的官方依赖下载/修复与跟随系统、浅色、深色主题选择。

## 验证与开始使用

Linux 77 项回归、Windows 原生 GUI 19 项，以及两平台严格 Clippy 通过。最终 release 已用受管官方 Core 通过托盘退出、后台/Core 生命周期、Job 清理和默认数据目录的 Windows 原生验收。详见 [C17 收口](../phase0-2-c17-closeout.md)。

从 [发布页](https://github.com/muidea/xray-pilot/releases/tag/v0.1.1-rc.3) 下载 Windows x64 zip 与 SHA256SUMS，核对后完整解压到可写位置。按 [README](../../README.md) 自动准备官方依赖并配置连接。

完全退出旧程序后再替换文件。需要保留 rc.2 及更早默认目录的配置时，用 `--data-dir "$env:LOCALAPPDATA\XrayManager"` 启动；后续 CLI 和快捷方式使用相同参数。安装目录下的新 data 不会自动读取旧配置。

真实 WinINet 往返、实际登录、跨用户访问、完整 GUI 交互和系统故障矩阵继续保留。PAC、TUN、Windows 服务、应用自动更新及历史自动清理仍未提供。
