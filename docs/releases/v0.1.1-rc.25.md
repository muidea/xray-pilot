# Xray Pilot v0.1.1-rc.25

Windows x64 本地验证版，在 `v0.1.1-rc.24`（PAC 与 GeoSite 能力增强）的基础上，修复读取旧版验证包（如 `v0.1.1-rc.23`）`data/runtime/operations/*.json` 历史操作证据时触发 `OPERATION_RECOVERY_REQUIRED` 的兼容问题。**本版尚未发布到 GitHub Release**。

## 本次变化

- **历史操作证据签名按原始持久化 JSON 校验与归档保留（`xray-supervisor`）**：
  - `OperationStore::verify` 与 `OperationStore::save` / `Operation::archive` 不再使用已升级后的 Rust 结构体字段重算 `request` 与整条记录的 `canonical_hash`，而是保留并在 `raw` 持久化 JSON `Value` 上验签及按需更新终态字段（`response`、`recovery_required`、`evidence_version`、`record_hash`）；
  - 直接覆盖升级自 `v0.1.1-rc.23` 及更早版本的 `data/` 目录时，先前执行过 `ApplyProfile` / `SetProxyMode`（含旧版 `PacDraft` 字段 `generated` / `template` / `template_mode`）的历史操作记录可在重启与压缩归档后无阻断通过完整性校验；
  - 严格防篡改语义保持不变：任何磁盘记录内容修改（含已弃用的历史 JSON 字段）、缺失或与 `request-identities` 不一致仍严格以 `OPERATION_RECOVERY_REQUIRED` 拦截。
- **回归验证**：
  - 新增 `operation_tests::legacy_pac_draft_operation_verifies_without_recovery_required`，覆盖 `v0.1.1-rc.23` 格式操作记录启动加载、查询、`archive()` 压缩重加载以及篡改旧字段仍触发 `OPERATION_RECOVERY_REQUIRED`。
- 完整保留 `v0.1.1-rc.24` 引入的 `geosite.dat`/`geoip.dat` 解析、`AutoRules` 与母域折叠、GeoSite 分组速选芯片/浏览器、路由国内外分流预设、静态路由 Geo 预测等全部功能与交互改进。
