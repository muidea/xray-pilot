# Xray Pilot v0.1.1-rc.19

Windows x64 本地验证版，完善 PAC 代理域名的批量管理、大列表展示性能与底层模板生成结构。**本版尚未发布到 GitHub Release**。

## 本次变化

- **PAC 批量管理**：
  - 单行输入支持用逗号、分号或空格分隔一次添加多条域名；
  - 新增 **批量粘贴 / 编辑…** 对话框，支持“追加（自动去重）”与“替换全部”，支持填入当前清单编辑，自动忽略空行与 `#` / `//` 注释，全无效替换保留原清单并定位错误行；
  - 支持导入纯文本域名列表（`.txt` / `.list` / `.conf`）、导出列表（`.txt`）及复制到剪贴板；
  - 新增 **从路由规则提取**，从当前配置的 `routing.rules` 提取明文域名规则，遇到 `geosite:`、`regexp:`、`ext:` 时自动跳过并明确提示其作用边界；
  - 新增 **去重排序** 与 **清空全部**（需二次确认）。
- **大列表展示与交互优化**：
  - 新增关键词搜索与规则类型筛选（全部 / 含主域 / 仅子域 / 精确匹配），实时显示总数、匹配数与已选数；
  - 支持 **全选当前**、**取消选择** 与 **移除所选 (N)**；
  - 域名清单改用固定高度虚拟滚动列表（`ScrollArea::show_rows`），数千条域名下只渲染可见行，不再撑长页面或卡顿。
- **PAC 模板生成优化**：
  - 内置模板的 `ProxyList` / `DirectList` 改用顶层 ES3 对象字面量配合 `hasOwnProperty` 与点分段查表，显著缩小脚本体积并避免超长 `||` 表达式导致的解析栈溢出，保持 WinINet JScript 兼容与原有匹配语义。

## 验证

全工作区 **216 项**常规回归通过，7 项需显式环境用例忽略（含 `xray-pac` 5,000 条域名模板校验/求值、批量解析、路由提取跳过 `geosite:`，以及 `xray-manager-app` 2,000 条域名虚拟滚动与批量弹窗回归）。Linux 与 Windows GNU 双目标严格 Clippy、`cargo fmt --check` 通过。

真实 Windows WinINet / PAC URL 往返、JScript 客户端缓存及完整桌面实操仍需按 V01 / V08 / V10 验收。
