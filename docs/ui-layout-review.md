# 界面长内容与滚动布局复核

2026-11-10，针对用户反馈的预览提示重叠，扩展核对当前五页原生界面、各编辑标签和弹窗。本文对应当前本地源码，尚未公开发布；验证包的具体输入以包内 SOURCE-MANIFEST.json 为准。

## 确认的问题和修复

1. 预览和导入对滚动正文设置了有限高度，长配置与大量提示叠加时出现文本重叠。现在只限制滚动视口，正文自然增长；编辑器使用显式尺寸预算。预览提供中文能力限制摘要、可展开的逐字段详情和独立滚动，新候选隔离滚动及展开状态。
2. 配置主页面存在同类正文高度约束。760×500 下叠加断线、恢复和错误卡片，滚动后能复现页面标题与说明文字重叠。现在主滚动正文不设高度上限，配置列单独接收可用高度，空间不足时页面可继续滚动。
3. 全局底部状态消息没有高度边界，多行长消息可挤占整个工作区。现在状态栏显示单行摘要，“完整消息”提供限高滚动全文与复制入口，不丢弃原消息。
4. Windows 系统中文字体下，配置页底部的长运行名称换行后会与草稿说明重叠。现在运行名称独立成行，与操作按钮分开排布，六个配置标签共用此修复。

另外统一补强 11 类确认弹窗：标题和取消 / 确认操作位于滚动正文之外。长配置名称和长 HTTP 入站 Tag 可以滚动查看，按钮保持可见。确认行为和后台请求合同保持原样。

## 验证方法与边界

- 全页组合回归覆盖 Light / Dark、760×500 / 1100×760 / 1920×1040，共 78 个页面 / 标签组合。通过实际指针展开和滚轮输入，核对裁剪后每行字形的可见边界，避免多行文本整体包围框或右对齐造成误判；另外确认结构化字段、诊断证据、依赖错误确实进入展开检查。
- 确认弹窗另外覆盖 66 个主题 / 尺寸 / 操作组合。预览专项滚动读取 40 条长提示，并核对候选切换后位置和展开状态。全部使用合成配置和错误信息，不读取用户凭据，也不启动这些合成配置。
- Linux GUI 47 项、Windows 原生 GUI 49 项全部通过。最终源码的 `cargo fmt --all -- --check`、Linux / Windows GNU GUI 全目标严格 Clippy 通过，Windows GNU 工作区 release 构建通过。
- Windows 原生测试图元和系统字体图集保存在当前 Windows 用户临时目录 `xray-preview-validation-5a3s_20v/layout-captures`。重新渲染并目视检查最小窗口的配置底部、诊断展开内容、依赖列表和长日志；长运行名称、按钮及草稿说明分别占行，未见重叠。
