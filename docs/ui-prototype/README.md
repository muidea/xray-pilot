# 界面交互设计预览

状态：**已确认的设计参考（2026-11-10）**。本目录是独立静态 Web 原型，不替换正式 Rust / egui 界面，也不代表这些交互已在发布版本中实现。

直接用浏览器打开 [index.html](index.html)，无需安装依赖。也可以在项目根目录启动本机预览：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/ui-prototype
```

访问 <http://localhost:8765/>。停止服务按 `Ctrl+C`。网页不加载外部字体、脚本或图片；只有主动点击官方发布页链接才会打开外部网站。

## 建议体验顺序

1. **日常运行**：总览查看 Core、当前运行配置与代理归属；在设置 → 外观中切换浅色、深色、跟随系统。
2. **编辑与应用**：配置 → 旅行网络 → 原始 JSON，修改入站端口；返回总览，运行配置仍是工作网络。回到配置，检查并预览 → 确认应用，运行配置才更新。
3. **首次安装**：顶部场景选择首次安装 → 模拟安装官方依赖 → 直连模板或粘贴 JSON → 检查预览 → 确认启动。默认不接管系统代理。
4. **异常反馈**：后台断开时显示最后已知状态并禁用写入；需要恢复时查看冲突证据；应用失败时保留原运行版本；结果待确认时按请求身份查询，不重复提交。
5. **托盘与退出**：窗口右上角关闭按钮收起到托盘；顶部托盘预览可打开窗口、仅退出界面或停止并退出整个程序。仅退出界面后，托盘随之消失，通过「重新打开界面」演示再次启动。

顶部「重置」恢复当前场景。刷新页面会清空模拟配置、草稿、运行状态和日志；仅主题选择尝试保存在本浏览器中。

## 已确认的交互选择

| 决策 | 本原型提案 |
| --- | --- |
| 一级导航 | 总览 / 配置 / 诊断 / 日志 / 设置；入站、出站、路由、原始 JSON 收入配置页 |
| 首页信息 | 优先显示 Core 状态、运行配置、本机入口、代理归属与最近活动 |
| 配置应用 | 草稿与运行快照分开；编辑、载入历史不执行；检查后明确预览与确认 |
| 代理文案 | 不接管系统代理 / 使用本机 HTTP 代理；不把解除接管描述为关闭所有代理 |
| 退出动作 | 收起窗口 / 仅退出界面 / 停止 Core、恢复代理并退出程序 |
| 显示风格 | 浅色 / 深色 / 跟随系统；全页面一致 |

## 能力与模拟边界

- 所有下载、校验、应用、恢复、连接与退出均为模拟；不调用真实后台、Core、Windows 代理或计划任务，不读写用户配置目录。
- JSON 可编辑、格式化，条目可添加、编辑、移动、删除；导入使用粘贴方式。条目编辑暂用小型 JSON 编辑器呈现流程，正式界面可细化协议表单。
- 检查只验证浏览器内的 JSON 基础结构，**不替代真实 `run -test`、资源完整性检查或入口握手**。工作网络使用 `example.test`，不能连接真实服务。
- 预览左右展示当前运行 JSON 和待应用 JSON，尚未提供逐行差异高亮；下载进度与操作时延均为演示。
- 路由页采用有限的保守演示模型，遇到未知或需要解析的前序条件返回未知，不代替正式诊断器。真实网络和实际出口始终未验证，不展示虚构流量或测速。
- 配置显示名称、草稿管理、日志筛选与新页面布局已获确认并在当前源码中落地，见 [原生界面实现与验证](../ui-implementation.md)。可发布能力以 [实现状态](../implementation-status.md) 与 [遗留清单](../phase0-2-backlog.md) 为准。
- “不接管”释放本程序持有的控制权并恢复先前设置，其他软件的代理仍可能有效。外部代理冲突必须核对证据；原型不提供删除租约或无条件覆盖的入口。

设计意图与状态约束见 [交互设计说明](../ui-interaction-design.md)。

## 本地验证

2026-11-10 使用 Playwright 1.65.0 与配套 Chromium headless shell 验证了五页导航、主题记忆、草稿与运行版本分离、检查 / 预览 / 应用、全部六种场景、首次安装引导、托盘三种退出行为、结构化编辑与未知字段保留、下载期间设置变更保护、日志暂停及忙碌时退出排队。1100×760、760×500、390×844 下主页面无整页横向溢出；直接 `file://` 打开可用，未出现页面脚本异常。

以上验证仅覆盖 Web 原型，不能替代正式 Windows GUI、Core 或代理集成验收。
